# AI Course Labs & Final Project

This repository contains my solutions for the AI Course labs and final project.

## Labs

### Lab 01 — URL Shortener

**Deployment:** https://ai-course-labs.vercel.app/

A simple URL shortener application demonstrating full-stack deployment fundamentals.

---

### Lab 02 — AI Code Analyzer

**Deployment:** https://ai-course-labs-code-analyzer.vercel.app/

An AI-powered code analysis tool that reviews source code and provides feedback using LLM-based analysis.

---

### Lab 03 — Migration Workflow Assistant

**Deployment:** https://ai-course-labs-ndzb.vercel.app/

A workflow assistant focused on helping analyze and plan codebase migrations.

---

### Lab 04 — RAG System

**Deployment:** https://ai-course-labs-a58z.vercel.app/

A Retrieval-Augmented Generation (RAG) application that:

* Indexes uploaded source files
* Chunks and embeds code
* Retrieves relevant context
* Generates grounded answers
* Evaluates retrieval quality using Precision@K, Recall@K, MRR, and a judge score

---

### Lab 05 — Multi-Agent Orchestration

**Deployment:** https://ai-course-labs-c4vn.vercel.app/

A multi-agent system featuring:

* Supervisor Agent
* Researcher Agent
* Writer Agent
* Task delegation workflow
* Activity feed
* Conversation history
* Final synthesized output

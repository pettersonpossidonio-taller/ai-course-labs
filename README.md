### Lab 04 — RAG System

**Deployment:** https://ai-course-labs-a58z.vercel.app/

A Retrieval-Augmented Generation (RAG) application that:

* Indexes uploaded source files
* Chunks and embeds code
* Retrieves relevant context
* Generates grounded answers
* Evaluates retrieval quality using Precision@K, Recall@K, MRR, and a judge score
